# 특수교육통계 제출자료 비교

학교 제출 엑셀과 특수교육통계 프로젝트 결과 엑셀(학교당 1개, 보통 42~43개교)을 비교한다.
저장소: `special-ed-staes-2` (compare.py, viewer/index.html).

## 원칙
- 두 파일에 들어 있는 값만 비교한다. 다른 자료를 더하거나 값을 추정·보정하지 않는다.
- 숫자는 엑셀 XML의 원문 글자를 `Decimal`로 읽어 비교한다 (float 금지). `1.0`=`1`, 글자로 저장된 `'6'`=6.
- 빈칸과 0은 다르게 본다 (`한쪽만 값 있음`). 글자는 띄어쓰기·줄바꿈만 다르면 같은 것으로 본다.
- 파이썬 표준 라이브러리만 쓴다 (오프라인, pip 불필요). openpyxl 없이 zipfile+xml 로 xlsx 를 읽는다.

## 절차
1. 학교 제출 파일을 `학교제출/`, 통계 결과 파일을 `통계결과/`에 둔다 (.xls 는 .xlsx 로 다시 저장).
2. `python compare.py --open` (Windows: `비교실행.bat` 더블클릭).
   - 한 학교만: `python compare.py --pair 학교.xlsx 통계.xlsx`
   - 다른 폴더: `-s 학교폴더 -t 통계폴더 -o 결과폴더`
3. 짝짓기는 파일명 속 학교명으로 한다 (`서울` 접두어, `초등학교→초` 자동 처리).
   못 맞춘 학교는 보고서에 `!`로 나오며 `학교제출/매칭표.csv`(학교파일명,통계파일명)로 지정한다.
4. 결과(`비교결과/`):
   - `비교결과_날짜.html`: 단일 파일 2분할 뷰어. 다른 셀 연두색, 아래 확인필요 목록 클릭 시 해당 셀로 이동, ↑↓ 이동.
   - `비교결과_날짜.json`: Vercel 웹 뷰어(viewer/index.html)에 끌어다 놓는 데이터.
   - `확인필요목록_날짜.csv`: 학교·시트·셀·행제목·열제목·학교값·통계값·차이(통계−학교)·유형.
5. 결과를 보고할 때는 학교 수, 확인필요 학교 수, 확인필요 셀 수, 짝을 못 찾은 파일을 먼저 알린다.

## 검증
- `python -m unittest discover tests`
- 새 서식이 들어오면 openpyxl 로 같은 비교를 독립 계산해 건수가 같은지 확인한다.

## 비교 유형
숫자 다름 / 한쪽만 값 있음 / 글자 다름 / 형식 다름 / 시트 없음. 시트는 이름 앞 번호(I-1, II-3 …)로 짝짓는다.
