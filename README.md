# 특수교육통계 2 — 학교 제출자료 비교기

학교에서 제출한 엑셀(나이스 **제출자료 조회**)과 **특수교육통계 프로젝트**가 만든 엑셀을
학교별로 짝지어 **모든 시트의 모든 셀**을 비교합니다. 42~43개교를 한 번에 처리합니다.

- 화면을 2분할해 왼쪽은 학교 제출, 오른쪽은 통계 결과를 보여주고, 값이 다른 셀은 **연두색**으로 표시합니다.
- 아래쪽 **확인필요사항** 목록을 누르면 해당 시트·셀로 바로 이동합니다 (↑↓ 키로 다음/이전).
- **인터넷 없이** 동작합니다. 파이썬 표준 라이브러리만 쓰므로 따로 설치할 패키지가 없습니다.
- 숫자는 엑셀에 저장된 글자 그대로를 `Decimal`로 읽어 비교하므로 소수점 오차가 없습니다.
- 두 파일에 들어 있는 값만 비교합니다. 다른 자료를 더하거나 추정하지 않습니다.

## 사용법 (Windows)

1. [Python 3](https://www.python.org/downloads/)을 한 번 설치합니다 (설치 화면에서 *Add python.exe to PATH* 체크).
2. `학교제출` 폴더에 학교에서 받은 엑셀 42~43개를 넣습니다.
3. `통계결과` 폴더에 특수교육통계 프로젝트가 만든 엑셀을 넣습니다.
4. `비교실행.bat`을 더블클릭합니다. 끝나면 보고서가 브라우저로 열립니다.

맥은 `비교실행.command`를 더블클릭하거나 터미널에서 `python3 compare.py --open`을 실행합니다.

결과는 `비교결과` 폴더에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `비교결과_날짜.html` | 2분할 비교 화면. 이 파일 하나만 있으면 어느 컴퓨터에서든 열립니다. |
| `비교결과_날짜.json` | 같은 결과의 데이터. 웹 뷰어(Vercel)에 끌어다 놓아 볼 수 있습니다. |
| `확인필요목록_날짜.csv` | 다른 셀 전체 목록. 엑셀에서 바로 열립니다. |

### 학교 짝짓기

파일 이름 속 학교명으로 짝을 짓습니다. `제출자료 조회_서울동답초등학교.xlsx` ↔ `동답초_특수교육통계_제출자료.xlsx`
처럼 `서울`, `초등학교→초` 차이는 자동으로 맞춥니다. 짝을 못 찾은 학교는 목록에 **!** 로 표시됩니다.
자동으로 안 맞는 학교는 `학교제출/매칭표.csv`에 직접 적어 줍니다.

```csv
제출자료 조회_서울동답초등학교.xlsx,동답초_특수교육통계_제출자료.xlsx
```

### 명령줄

```bash
python compare.py                                   # 기본 폴더 일괄 비교
python compare.py -s 학교폴더 -t 통계폴더 -o 결과폴더
python compare.py --pair 학교파일.xlsx 통계파일.xlsx  # 한 학교만
```

## 비교 규칙

| 유형 | 뜻 |
|---|---|
| 숫자 다름 | 두 파일 모두 숫자인데 값이 다름. 차이는 `통계 결과 − 학교 제출` |
| 한쪽만 값 있음 | 한쪽은 빈칸, 다른 쪽은 값(0 포함)이 있음 |
| 글자 다름 | 제목 등 글자가 다름 (띄어쓰기·줄바꿈 차이는 같은 것으로 봄) |
| 형식 다름 | 한쪽은 숫자, 다른 쪽은 숫자가 아닌 글자 |
| 시트 없음 | 한쪽 파일에만 있는 시트 |

- 시트는 이름 앞의 번호(`I-1`, `II-3` …)로 짝짓습니다.
- 나이스가 숫자를 글자로 저장한 칸(`'6'`)은 숫자로 보고 비교합니다. `1.0`과 `1`은 같습니다.
- `.xls`(옛 형식)는 읽지 않습니다. 엑셀에서 `.xlsx`로 다시 저장해 주세요.

## 웹에서 바로 비교 (Vercel)

`viewer/index.html` 하나가 Vercel에 배포되는 페이지입니다. 파이썬 없이도 쓸 수 있습니다.

1. **① 학교 제출 엑셀** 칸에 학교 파일들을, **② 특수교육통계 결과 엑셀** 칸에 결과 파일들을 넣습니다 (여러 개, 끌어다 놓기 가능).
2. **비교 시작**을 누르면 같은 2분할 화면이 나옵니다. **목록 CSV 저장**으로 확인필요 목록을 내려받습니다.

- 엑셀은 브라우저 안에서 직접 풀어 읽고 비교하며, 파일은 서버로 전송되지 않습니다. 외부 라이브러리를 쓰지 않아 인터넷 없이 이 파일만 열어도 동작합니다.
- 비교 규칙은 `compare.py`를 그대로 옮긴 것이고, 숫자는 BigInt로 정확하게 비교합니다. 같은 파일로 돌리면 파이썬 결과(json)와 글자 하나까지 같습니다.
- 파이썬이 만든 `비교결과_날짜.json`도 첫 화면 아래 링크로 열 수 있습니다.
- 크롬·엣지 최신판을 권장합니다.
